# 동네노트
한국 아파트 검색 → 네이버 지도 이동 → 사용자가 동 위치·이름 등록 → 동별 방문일·메모·사진 기록. 개인용으로 배포하며 플랫폼 로그인과 사용자별 서버 저장을 사용한다. 데스크톱은 검색/지도/기록 3열, 모바일은 단계별 패널이다.
검토: 건물 윤곽 자동 식별은 동 번호 데이터가 불완전하여 제외. 사용자가 선택한 동 위치 마커 방식을 채택. 네이버 지도는 사용자 선택이다.
구현자 결정: 서버 Worker + 의존성 없는 웹 UI, 사용자별 R2 저장, 낙관적 잠금, 사진 5MB 이하 최대 12장/기록. 키 없는 상태는 설정 안내와 저장하지 않는 명시적 샘플 제공. 비공개 배포를 유지하며 공개 공유 기능은 범위 밖이다.
